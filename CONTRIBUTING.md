# Contributing

Thanks for your interest in contributing to this project.

This project is under active development, and contributions, bug reports, suggestions and improvements are welcome.

## Ways to contribute

You can help by:

* Reporting bugs.
* Suggesting improvements or new features.
* Improving documentation.
* Fixing existing issues.
* Testing the plugin and reporting unexpected behaviour.
* Submitting code improvements.

## Issues

Before starting work, check the existing Issues.

Issues labelled `good first issue` are intended to be relatively approachable for new contributors.

If you find a bug or have an idea that is not already listed, feel free to open a new Issue.

Please include as much information as possible, particularly:

* What you expected to happen.
* What actually happened.
* Steps to reproduce the problem.
* Relevant version or environment information.

## Pull Requests

If you want to contribute code:

1. Fork the repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test them before submitting.
5. Open a Pull Request explaining what you changed and why.

Whenever possible, reference the corresponding Issue in your Pull Request.

## Questions and ideas

Not every idea needs to become an Issue immediately.

Questions, broader ideas and possible future improvements can be discussed in GitHub Discussions.

## Development status

This is an actively developed project. Some parts of the codebase and documentation may still change considerably.

Constructive feedback and contributions are welcome.
