HISTORIAL DE ORIGEN — TAXOCOMMERCE CONNECTIONS

Etapa: TaxoCommerce SEO monolítico (hasta 2.4.1).
Este archivo relata funciones originales y antecedentes; NO corresponde a versiones del plugin autónomo.
Fuente primaria: https://github.com/distribuidordeherramientases-wq/seo-taxonomy/blob/staging/CHANGELOG.md
Las fechas solo se muestran si aparecen en la fuente original; no se inventan versiones autónomas.

ORIGEN FUNCIONAL Y EXTRACCIÓN
* Historical source: the monolith provided Google Search Console, GA4, Bing and related external connections; the separate Connections plugin is not the original owner of that history.
* Standalone 0.2.0 isolated the connection bridge while Insights was being extracted, preserving existing OAuth paths, configuration and provider integration contracts.
* The connection engine and related screens were later consolidated into Insights rather than maintained as two competing sources of truth.
* Standalone 0.3.0 is a compatibility bridge for existing installations: migration and deactivation must preserve provider settings and not silently create new credentials.
* Later Insights versions introduced provider-status diagnostics and authorised manual verification; those updates belong to Insights, not to new releases of this bridge.

## [2.3.10] - 2026-10-06
Origen: TaxoCommerce SEO 2.3.10 (no es una versión de Connections).
- El radar usa **Google Trends** para señales crecientes y valida cada candidato con **Google Shopping + Google Search** mediante la conexión compartida SerpApi → ScraperAPI; conserva fuentes, cobertura, score explicable y estado humano sin crear categorías/productos automáticamente.

Origen: TaxoCommerce SEO 2.3.9 (no es una versión de Connections).

[Auditor, Analista y control de calidad] - Alineados los informes de GSC/GA4, excluyendo pruebas administrativas cuando corresponde y completando métricas de páginas.

[Comparador, carrito y documentos comerciales] - Corregidas las imágenes del carrito para admitir imágenes externas activas de proveedores y variaciones.
