# SEO Taxonomy

Plugin de WordPress para la gestión, organización y optimización SEO de catálogos de productos.

## Descripción

SEO Taxonomy está diseñado para trabajar con catálogos de productos en WordPress y WooCommerce, facilitando la gestión de taxonomías, categorías, contenidos y procesos relacionados con SEO.

## Funcionalidades

* Gestión de taxonomías y categorías.
* Herramientas SEO para catálogos de productos.
* Informes y análisis.
* Automatización de tareas relacionadas con contenidos.
* Integración con procesos externos y scrapers.
* Soporte para flujos de trabajo con WooCommerce.

## Estado del proyecto

Proyecto actualmente en desarrollo.

Repositorio principal del plugin completo.

## Requisitos

* WordPress
* WooCommerce
* PHP compatible con la versión de WordPress instalada

## Instalación

1. Descargar el plugin.

2. Subir la carpeta `seo-taxonomy` a:

   `wp-content/plugins/`

3. Activar **SEO Taxonomy** desde el panel de administración de WordPress.
