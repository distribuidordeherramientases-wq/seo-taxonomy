# Imágenes

Ruta: **SEO Taxonomy → Imágenes**

## Pestañas

- Inventario
- Anomalías
- Asignación
- Errores
- Liberar espacio

## Inventario

Muestra:

- formatos existentes en Media local;
- imágenes externas agrupadas por proveedor;
- Media local.

Las tablas permiten conocer proveedor, número de imágenes, productos, promedio, referencias sin product_id, ID de medio, nombre, tamaño y URL según la sección.

## Anomalías

### Productos con pocas imágenes externas

- **Proveedor**: limita el análisis.
- **Marcar si tiene menos de**: umbral de imágenes.
- **Aplicar** [Consulta].

Tabla: Proveedor, Producto, SKU, Imágenes y Ver.

### Otras anomalías

- Imágenes externas sin producto.
- Productos sin imagen utilizable.
- Referencias de Media que ya no existen.
- Media local sin referencias.

Los botones de cada bloque actúan sobre la anomalía indicada. Antes de eliminar una referencia o un medio, comprobar que no exista un uso válido fuera del inventario detectado.

## Asignación

- **Asignar automáticamente hasta 25** [Modifica]: intenta asociar candidatos relacionados en un lote limitado.
- tabla Elemento / Candidatos relacionados.
- **Asignación manual**: permite elegir un elemento concreto.
- **Subir y asignar** [Guarda]: incorpora el archivo y crea la relación.

## Errores

Ejecuta el escáner técnico del ámbito imágenes.

## Liberar espacio

Lista Media local sin referencias y permite marcar elementos.

**Eliminar seleccionadas sin uso** [Elimina] borra los medios seleccionados que la pantalla considera sin uso. Es una acción destructiva.
