# Páginas

Ruta: **SEO Taxonomy → Páginas**

## Pestañas

- Estructura SEO
- Landings
- Informe landings
- Corporativas
- Errores

## Alta y edición

Campos comunes:

- **Título**.
- **Slug**.
- **Rol SEO**.
- **Estado**.
- **Extracto**.
- **Contenido**.

Acciones:

- **Crear borrador** [Guarda]: crea una página sin publicarla.
- **Guardar esta página** [Guarda][Producción si está publicada].
- **Descartar del mapa** [Modifica]: retira la página de la estructura gestionada sin equivaler a borrarla de WordPress.
- **Borrar de WordPress** [Elimina]: elimina el objeto WordPress; es distinta de “Descartar del mapa”.

## Estructura SEO

Trabaja con páginas de rol Cluster, Hub primario y Hub secundario. Los selectores de relación permiten situar la página en la estructura.

## Landings

Además del contenido, muestra la relación comercial:

1. Cluster.
2. Hub primario.
3. Hub secundario.
4. Categoría de producto.

Controles:

- **Añadir categoría seleccionada** [Guarda].
- **Búsqueda directa de product_cat** [Consulta]: localiza una categoría por búsqueda directa.
- **Añadir directa** [Guarda].
- las categorías seleccionadas pueden retirarse de la selección antes de guardar.

## Informe landings

### Candidata editorial

Campos:

- Título de trabajo.
- Tipo.
- Fuente.
- Estado.
- Intención / qué quiere resolver el comprador.
- Destino existente parecido.
- Por qué necesita una página diferente.
- Requisitos obligatorios.
- Prioridad de la candidata válida.
- **Guardar candidata** [Guarda].

La página incluye bloques de ayuda: Requisitos obligatorios, Test del comprador, Estructura editorial recomendada, Qué NO es una buena landing, Regla de decisión, Test definitivo y Priorización de candidatas.

### Seguimiento

- Rendimiento de landings.
- Señales externas.
- **Sincronizar para revisión** [Proceso/Guarda según la fuente].
- Landings existentes: ID, estado, contador 30d, GA4, GSC y fecha de actualización.
- Candidatas y decisiones.
- Huecos de cobertura por Hub secundario.

## Corporativas

Muestra páginas de rol corporativo. No exige relación directa con product_cat.

## Errores

Usa el escáner de salud para las páginas WordPress publicadas. Los botones de iniciar/parar y los filtros funcionan igual que en la pestaña Errores de otros objetos.
