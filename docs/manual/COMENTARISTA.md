# Comentarista

## Pestañas
**Registros**, **Cobertura**, **Importar / Exportar**, **JSON**.

## Registros
Campos Producto, Tipo, Plataforma, Fuente, URL origen, ID externo, Título, Autor, URL autor, Fecha original, Fecha captura, Contenido capturado, Resumen editorial, Valoración/escala, URL embed, Miniatura, Estado y Orden.

**Guardar / Actualizar**, **Cancelar**; listado con **Editar** y **Eliminar** con confirmación.

## Cobertura
KPIs y segmentos Todos / Sin evidencias / 1-4 / 5-10 / >10. Filtros Buscar producto y Categoría, **Filtrar** / **Limpiar**. Tabla con **Gestionar** y **Producto**.

## Importar / Exportar
**Exportar Comentarista**, selector CSV, **Importar Comentarista**.

## JSON
ID de producto opcional, **Consultar**, **Ver global**, **Descargar JSON** y salida de solo lectura.
