# Páginas

## Pestañas
1. **Estructura SEO**
2. **Landings**
3. **Informe landings**
4. **Corporativas**
5. **Errores**

**Estructura SEO** gestiona páginas que participan en la arquitectura.  
**Landings** administra páginas orientadas a intención de búsqueda o campañas.  
**Informe landings** presenta inventario, estado y rendimiento.  
**Corporativas** separa contenido institucional.  
**Errores** centraliza incidencias.
