# Ojeador

Observa el mercado externo por categorías y productos mediante Google Shopping.

## Pestañas
1. **Análisis y recomendaciones**
2. **Posición de precio**
3. **Comparador de productos**
4. **Operación y consultas**

La posición de precio utiliza tres estados operativos: competitivo, dentro de mercado y desfavorable.

Acciones principales: **Continuar / actualizar mercado**, **Detener**, **Recalcular**, filtros y exportaciones JSON.
