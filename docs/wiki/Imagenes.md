# Imágenes

## Pestañas
1. **Inventario**
2. **Anomalías**
3. **Asignación**
4. **Errores**
5. **Liberar espacio**

El sistema controla Media local, imágenes externas por proveedor, productos sin imagen, referencias rotas, recursos sin uso y asignación de imágenes relacionadas.

Las operaciones de borrado requieren especial precaución porque pueden ser destructivas.
