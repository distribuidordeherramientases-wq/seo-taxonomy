# Clonador

Servicio de sincronización espejo **PRO → STAGING**.

## Flujo
1. **Simular clonación**
2. revisar el plan
3. **ARRANCAR CLONACIÓN**
4. monitorizar
5. verificar
6. **REVERIFICAR COPIA** si es necesario

Controles: **PARAR**, **− FRENO**, **ACELERADOR +**, **Descargar JSON del plan**.

Durante la clonación deben permanecer parados otros procesos que escriben datos, especialmente Academia, Lingüista e Import / Export.

PRO es origen y no debe modificarse.
