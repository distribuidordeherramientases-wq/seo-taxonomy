# Arquitectura y conceptos

## Jerarquía SEO
**Cluster → Hub primario → Hub secundario → Categoría → Producto**

## Semántica
Vocabularios principales: **ROL, TIPO, APLICACIÓN, PLATAFORMA, SUBTIPO**.

## Fuentes canónicas
Productos, categorías, páginas/posts, relaciones, Vocabulary, atributos, FAQs y configuraciones editoriales.

## Capas derivadas
Índices, análisis, puntuaciones, propuestas, aprendizaje, logs e informes.

## Responsabilidades
- Ojeador observa mercado
- Analista interpreta señales
- Auditor detecta incoherencias
- Dependiente atiende y aprende
- Intérprete traduce lenguaje a semántica
- Academia/Lingüista forman el sistema
- Comentarista aporta evidencia
- Solucionador detecta necesidades editoriales
- Clonador reconstruye STAGING desde PRO
