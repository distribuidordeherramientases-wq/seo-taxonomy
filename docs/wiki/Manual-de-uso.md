# Manual de uso

El manual sigue la navegación real del panel **SEO Taxonomy**.

| Menú | Finalidad |
|---|---|
| **Inicio** | Presentación general y acceso a áreas del plugin. |
| **Productos** | Alta, edición, inventario, recategorización, tamaños, Google y errores. |
| **Categorías** | Gestión SEO, estructura, reasignación, inventario y catálogo. |
| **Etiquetas** | Vocabularios semánticos, atributos, asignación y esquema Google. |
| **Páginas** | Estructura SEO, landings, corporativas e incidencias. |
| **Entradas** | Posts, oportunidades editoriales y errores. |
| **Imágenes** | Inventario, anomalías, asignación, errores y limpieza. |
| **Informes** | Informes SEO, paneles, contenido, anomalías y Analista. |
| **Dependiente** | Búsqueda guiada, aprendizaje, Academia, Intérprete y Auditor. |
| **Herramientas** | Utilidades avanzadas y transversales. |

Cada página distingue acciones de lectura, análisis, escritura y procesos largos.
