# Servicios

Los **Servicios** son motores funcionales que aportan capacidades transversales.

| Servicio | Función principal |
|---|---|
| [[Clonador]] | Reconstrucción controlada de STAGING a partir de PRO |
| [[Ojeador]] | Mercado y Google Shopping |
| [[Dependiente]] | Búsqueda guiada y aprendizaje supervisado |
| [[Academia, Intérprete y Lingüista|Academia-Interprete-y-Linguista]] | Formación y comprensión semántica |
| [[Analista]] | Análisis estratégico |
| [[Comentarista]] | Evidencia y contenido externo |
| [[Auditor]] | Control de calidad y coherencia |
| [[Solucionador]] | Necesidades y cobertura editorial |

Principio común: distinguir entre **observar**, **proponer**, **validar** y **modificar**.
