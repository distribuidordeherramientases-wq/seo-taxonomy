# Productos

El menú **Productos** concentra las operaciones de administración del catálogo.

## Pestañas

1. **Nuevo producto**
2. **Editar producto**
3. **Inventario**
4. **Recategorizar**
5. **Tamaños**
6. **Informes Google**
7. **Errores**

### Nuevo producto
Crea productos desde el entorno de SEO Taxonomy manteniendo integración con WooCommerce y la capa semántica.

### Editar producto
Mantenimiento individual de datos comerciales, editoriales y semánticos.

### Inventario
Control agregado del catálogo para localizar productos y revisar estados.

### Recategorizar
Revisión y modificación de pertenencia a categorías. Afecta navegación, SEO, relaciones y entrenamiento.

### Tamaños
Analiza peso y dimensiones para detectar valores anómalos que puedan afectar a logística o portes.

### Informes Google
Agrupa señales y datos de Google relacionados con los productos.

### Errores
Centraliza incidencias detectadas para productos.

## Relación con otros servicios
Productos alimenta Dependiente, Auditor, Ojeador, Clasificador, informes y procesos de proveedores.
