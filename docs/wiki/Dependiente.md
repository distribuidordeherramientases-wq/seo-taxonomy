# Dependiente

Sistema de búsqueda guiada y asistencia al cliente.

## Pestañas
1. **Configuración**
2. **Informe**
3. **Aprendizaje**
4. **Academia**
5. **Intérprete**
6. **Conocimiento**
7. **Auditor**

Configuración incluye **Reindexar catálogo completo**, **Vaciar índice**, piloto, página pública y fuentes.

El aprendizaje es supervisado: los candidatos pueden **Aprobarse** o **Rechazarse**.

Existe una zona peligrosa para borrar conocimiento derivado; el catálogo canónico se conserva, pero índices y conocimiento deben reconstruirse.
