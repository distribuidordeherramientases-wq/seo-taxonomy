# TaxoCommerce SEO 2.4.0

**Fecha de corte:** 13/10/2026  
**Nombre público:** TaxoCommerce SEO - Catalog, Trends, Content & Feeds  
**Slug solicitado en WordPress.org:** `taxocommerce-seo`

## Objetivo de la release

La versión 2.4.0 inaugura la línea pública **TaxoCommerce SEO 2.4.x** y consolida el trabajo integrado en staging desde la serie 2.3.x.

El cambio de nombre es una evolución de identidad pública, no una reinstalación del producto. Los datos existentes deben conservarse.

## Compatibilidad

Se mantienen los identificadores internos históricos cuando forman parte de la compatibilidad de una instalación existente:

- constantes `SEO_SYSTEM_*`;
- nombres de clases y funciones;
- tablas de base de datos;
- opciones y metadatos;
- slugs administrativos internos;
- rutas operativas y claves persistentes.

No deben renombrarse de forma masiva sólo por el cambio de marca.

## Cambios de identidad pública

- Cabecera del plugin: **TaxoCommerce SEO - Catalog, Trends, Content & Feeds**.
- Versión global: **2.4.0**.
- `SEO_SYSTEM_VERSION`: **2.4.0**.
- Stable tag público: **2.4.0**.
- Text Domain público: **taxocommerce-seo**.
- Documentación, Wiki y textos visibles: **TaxoCommerce SEO**.
- Carpeta esperada para el paquete de WordPress.org: `taxocommerce-seo`.

El archivo principal puede seguir llamándose `seo-taxonomy.php`; el nombre del archivo PHP no define el nombre público del plugin.

## Consolidación funcional incluida

La release recoge las mejoras ya integradas y validadas en staging, entre ellas:

- evolución de Dependiente y su medición de uso;
- estadísticas separadas de Google Analytics, Search Console y actividad interna de Dependiente;
- exportación JSON para análisis de Dependiente;
- evolución de Ingeniero con investigación técnica, práctica y de actualidad;
- mejoras de Auditor, Ojeador, Analista y Solucionador;
- mejoras de Import / Export;
- integración de la cola general con el Gestor de workers;
- continuidad y recuperación de procesos largos;
- mejoras de documentación, Wiki y trazabilidad operativa.

## Regla de versiones a partir de este corte

La línea activa pasa a ser:

```text
2.4.0
2.4.0.1
2.4.0.2
...
```

Los parches de esta release usarán `2.4.0.*`. Un cambio funcional que justifique una nueva minor abrirá una futura línea `2.4.1` o la versión que Dirección determine.

## Validación previa a producción / WordPress.org

Antes del corte final:

1. comprobar coherencia de versión entre cabecera, constante y `readme.txt`;
2. ejecutar PHP lint;
3. ejecutar Plugin Check;
4. verificar activación sin fatal errors;
5. comprobar menús principales;
6. comprobar procesos y workers;
7. comprobar importación/exportación;
8. comprobar Dependiente y frontend;
9. verificar que no se distribuyen credenciales ni archivos de trabajo;
10. confirmar que WordPress.org ha reservado el slug `taxocommerce-seo`.

## Nota sobre el rebranding

**SEO Taxonomy** es el nombre histórico del proyecto y puede seguir apareciendo en identificadores internos o documentación histórica cuando tenga valor de trazabilidad. Para cualquier interfaz, documentación vigente o distribución pública, el nombre actual es **TaxoCommerce SEO**.
